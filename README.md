# 차담

차 안 대화를 동승자 폰에 실시간 자막으로 띄우고, 동승자가 폰에 쓴 글은 차 스피커로 읽어 주어, 듣거나 말하기 어려운 탑승자도 대화에 함께하게 하는 Pleos 차량 앱입니다.

현대자동차그룹 차량용 앱 개발 공모전(2026) 출품작입니다.

## 구성

| 폴더 | 내용 |
|---|---|
| `car-pleos/` | 차 앱 (Pleos Connect, Kotlin). 차 마이크로 말을 받아 폰으로 보내고, 폰에서 온 음성을 차 스피커로 재생합니다. 기어·주행 상태로 정차를 확인할 때만 세션을 엽니다. |
| `phone/` | 동승자 폰 앱 (Android, Kotlin). 차 화면의 QR을 찍어 연결하고, 차에서 온 소리를 폰 안의 음성 인식으로 자막을 띄웁니다. 쓴 글은 폰에서 음성으로 바꿔 차로 보냅니다. |
| `tools/` | 에뮬레이터 시연용 포트 전달기(`forward.mjs`, Node 코어 모듈만 사용) |
| `apk/` | 서명한 release APK 2개 |

클라우드 서버는 없습니다. 차와 폰이 같은 네트워크에서 직접 연결하고, 음성 인식은 동승자 폰 안에서만 합니다. 음성과 자막은 저장하지 않습니다.

차와 폰 사이 연결은 TLS 1.3으로 암호화합니다. 차가 세션마다 새 키를 만들고 QR에 그 키의 지문을 넣으므로, 폰은 QR을 찍은 그 차에만 연결합니다.

## APK

| 파일 | 설치할 곳 |
|---|---|
| `apk/차담_차담_release.apk` | Pleos Connect Emulator (차 앱) |
| `apk/차담_차담폰_release.apk` | 동승자 Android 폰, Android 13 이상 |

## 테스트 환경

- macOS(Apple Silicon), Pleos Connect Emulator 2.1.0에서 시험했습니다. Windows에서도 같은 순서로 쓸 수 있게 명령을 함께 적었지만, Windows에서는 직접 시험하지 않았습니다.
- 동승자 폰: Galaxy Note20 (Android 13). 한국어 기기 안 음성 인식이 되는 폰이어야 자막이 나옵니다.
- PC와 폰은 같은 Wi-Fi에 연결합니다.

## 처음부터 따라 하기

아래 순서대로 하면 PC(Mac 또는 Windows)의 Pleos 에뮬레이터(차)와 Android 폰(동승자)으로 차담을 직접 써 볼 수 있습니다. Mac과 Windows가 다른 곳은 둘 다 적었습니다.

### 0. 준비물

| 준비물 | 설명 |
|---|---|
| PC | Pleos Connect Emulator 2.1.0이 설치된 Mac 또는 Windows PC. PC 마이크가 차 마이크, PC 스피커가 차 스피커 역할을 합니다. 에뮬레이터 이미지는 Mac용과 Windows·Linux용 주소가 따로 있으니 [Pleos 설치 안내](https://document.pleos.ai/en/docs/connect/guide/getting-started/application-development/setup-connect-sdk-emulator)를 따릅니다. |
| Android 폰 | Android 13 이상. 동승자 역할입니다. 폰 안에서 한국어 음성 인식이 되어야 자막이 나옵니다(Galaxy Note20에서 확인). |
| 같은 Wi-Fi | PC와 폰을 같은 Wi-Fi에 연결합니다. 기기끼리 연결을 막아 둔 공용 Wi-Fi에서는 안 될 수 있습니다. |
| adb, Node.js | Mac은 터미널, Windows는 PowerShell에서 `adb`(Android SDK platform-tools)와 `node`를 쓸 수 있어야 합니다. 아래 명령은 따로 적은 곳만 빼고 두 곳에서 똑같이 씁니다. |

### 1. APK 내려받기

이 저장소의 `apk/` 폴더에 APK가 2개 있습니다. 파일을 누른 뒤 오른쪽 위 다운로드 버튼(Download raw file)을 누르면 받아집니다.

- **차 앱** `차담_차담_release.apk`: PC에 받습니다.
- **폰 앱** `차담_차담폰_release.apk`: 폰 브라우저로 이 저장소를 열어 받습니다. PC에 받아 폰으로 옮겨도 됩니다.

저장소를 통째로 받아도 됩니다. 2단계의 포트 전달기(`tools/forward.mjs`)도 여기 들어 있습니다.

```bash
git clone https://github.com/aslla77/chadam.git
cd chadam
```

### 2. 차 앱 준비 (PC)

1. **에뮬레이터를 켭니다.** PC 마이크를 차 마이크로 쓰려면 `-allow-host-audio`를 붙여 켭니다. Android Studio의 Device Manager로 켰다면 2번만 해도 됩니다.
   ```bash
   emulator -avd <내 Pleos AVD 이름> -allow-host-audio
   ```
   `emulator`를 못 찾으면 Android SDK 폴더의 `emulator` 안에서 실행합니다. 보통 Mac은 `~/Library/Android/sdk/emulator`, Windows는 `%LOCALAPPDATA%\Android\Sdk\emulator`(`emulator.exe`)입니다.
2. **PC 마이크를 에뮬레이터에 연결합니다.** 에뮬레이터 창 옆 도구 막대의 **⋯**(Extended Controls) → **Microphone** → **Enable Host Microphone Access**를 켭니다. 이걸 켜지 않으면 실행 옵션을 붙였어도 차 마이크에 소리가 들어가지 않습니다.
   - Mac: 마이크 사용 허용을 물으면 **허용**합니다. 거절했다면 시스템 설정 → 개인정보 보호 및 보안 → 마이크에서 다시 켭니다.
   - Windows: 설정 → 개인 정보 및 보안 → 마이크에서 **마이크 액세스**와 **데스크톱 앱이 마이크에 액세스하도록 허용**을 켭니다.
3. **차 앱을 설치합니다.**
   ```bash
   adb -s emulator-5554 install -r apk/차담_차담_release.apk
   ```
   예전에 다른 서명으로 설치한 차담이 있어 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`이 나오면, `adb -s emulator-5554 uninstall io.cabincaption.car`로 지운 뒤 다시 설치합니다.
4. **폰이 에뮬레이터에 들어올 수 있게 포트를 넘깁니다.** 에뮬레이터 안의 차 앱은 PC 바깥에서 바로 접속할 수 없어서, PC가 47100번 포트로 받아 에뮬레이터에 넘겨 줍니다. `<PC 주소>`에는 아래 5번에서 확인하는 PC의 Wi-Fi 주소를 넣습니다. 아래 두 줄을 실행하고, 시험하는 동안 이 터미널은 켜 둡니다.
   ```bash
   adb -s emulator-5554 forward tcp:47001 tcp:47000
   node tools/forward.mjs <PC 주소> 47100 47001
   ```
   - PC 주소 대신 `0.0.0.0`을 넣으면 PC의 모든 네트워크에서 포트가 열립니다. 시험하는 Wi-Fi 주소에만 여는 것이 안전합니다.
   - 방화벽이 `node`의 연결 허용을 물으면 **허용**합니다. Windows에서는 **개인 네트워크**에 체크합니다. 막으면 폰이 들어오지 못합니다.
   - 에뮬레이터를 다시 켰다면 `adb forward` 줄을 다시 실행합니다.
   - 실제 차에서는 폰이 차 앱에 바로 연결하므로 이 단계가 없습니다.
5. **PC의 Wi-Fi 주소를 확인합니다.** `192.168.0.10` 같은 주소입니다.
   - Mac:
     ```bash
     ipconfig getifaddr en0
     ```
   - Windows: PowerShell에서 `ipconfig`를 실행하고, **무선 LAN 어댑터 Wi-Fi** 아래의 **IPv4 주소**를 봅니다.

### 3. 차 앱 열고 연결 주소 맞추기 (에뮬레이터 화면)

1. 에뮬레이터 하단 바나 앱 목록에서 **차담**을 엽니다. 처음에는 마이크 권한을 물으니 **허용**합니다.
2. 기어가 P(정차)이면 QR과 **세션 연결중**이 바로 뜹니다.
3. 에뮬레이터에서는 연결 주소를 PC로 바꿔 줘야 합니다.
   1. **끄기**를 누릅니다.
   2. **연결 설정**을 누릅니다.
   3. **QR 주소**에 2-5에서 확인한 PC 주소, **포트**에 `47100`을 넣고 **저장**합니다.
   4. **세션 열기**를 누릅니다.
4. QR 옆에 방금 넣은 `PC 주소:47100`이 보이면 준비가 끝났습니다. 이 설정은 앱에 남아서 다음부터는 3번을 건너뜁니다.

### 4. 폰 앱 설치하고 연결하기 (Android 폰)

1. 받은 `차담_차담폰_release.apk`를 엽니다.
   - "출처를 알 수 없는 앱" 안내가 나오면 **설정**에서 이 출처(브라우저나 파일 앱)의 설치를 허용하고 돌아와 설치합니다.
   - 보안 경고가 나오면 내용을 확인하고 설치를 계속합니다.
2. **차담**을 열면 사용설명서 5장이 나옵니다. **다음**으로 넘기거나 **건너뛰기**를 누릅니다. 사용설명서는 홈에서 언제든 다시 볼 수 있습니다.
3. 홈의 **QR 찍기**를 누르고 카메라 권한을 **허용**합니다.
4. PC 화면의 에뮬레이터에 뜬 QR을 폰 카메라로 찍습니다.
5. 동의 화면 맨 위에 차 주소(`PC 주소:47100`)가 보이는지 확인합니다. **대화명**(다른 동승자에게 보이는 이름)을 정하고 **동의하고 연결**을 누릅니다.
6. 마이크 권한을 물으면 **허용**합니다.
   - Android의 음성 인식 기능을 쓰려면 이 권한이 필요합니다.
   - 차담은 폰 마이크를 켜지 않고, 차에서 보낸 소리만 인식합니다.
   - 거절해도 연결과 글 보내기는 되지만 자막은 나오지 않습니다.
7. 폰 위쪽에 **연결됨**, 차 화면에 **폰 1/4**와 내 대화명이 뜨면 연결이 끝났습니다.

### 5. 써 보기

**말 → 폰 자막**
- PC 마이크 가까이에서 평소처럼 말합니다. 폰에 **차** 말풍선으로 자막이 뜹니다.
- 말하는 동안에는 "차 · 듣는 중…"으로 뜨다가, 말이 끝나면 확정됩니다.

**글 → 차 스피커**
- 폰 아래 입력칸(**차 스피커로**)에 글을 쓰고 **보내기**를 누릅니다.
- 차 스피커(에뮬레이터에서는 PC 스피커)가 그 글을 읽어 줍니다.
- 내 말풍선 아래에 진행 상태가 뜹니다: **보내는 중…** → **보냄** → **재생 중** → **완료**. 차가 다른 글을 읽고 있으면 **대기 중**이 먼저 뜹니다.
- 차가 읽는 동안에는 차 마이크가 잠깐 쉽니다. 읽은 글이 다시 자막으로 돌아오지 않게 하기 위해서입니다.

**폰 위쪽 버튼 3개 (왼쪽부터)**

| 버튼 | 하는 일 |
|---|---|
| 멈춤 (⏸) | 모든 폰의 자막을 멈춥니다. 다시 누르면 시작합니다. 동승자 누구나 누를 수 있습니다. |
| 차 스피커 (🔈) | 끄면 입력칸이 **다른 폰으로**로 바뀌고, 글이 소리 없이 다른 동승자 폰에만 갑니다. 운전자나 내비 안내를 방해하지 않고 말을 전할 때 씁니다. |
| 나가기 | 연결을 끊고 이 폰의 자막과 글을 지웁니다. |

**폰 여러 대로 써 보기 (선택)**
- 다른 폰도 같은 방법으로 QR을 찍으면 4대까지 들어옵니다.
- 한 사람이 보낸 글은 다른 폰에도 그 사람의 대화명이 붙은 말풍선으로 뜹니다.
- QR은 한 번 쓰이면 새로 바뀌니, 차 화면에 지금 떠 있는 QR을 찍습니다.

**설정 (폰 홈 오른쪽 위 톱니바퀴)**
- 대화명 바꾸기
- 테마: 기기 설정, 기본 다크, 기본 라이트, 현대 블루, 현대 샌드, 기아 미드나잇, 고대비
- 개인정보 안내, 오픈소스 라이선스, 버전

### 6. 끝내기

- 차 화면에서 **끄기**를 누릅니다. QR이 사라지고 모든 폰의 연결이 끊기며, 폰에는 **차 꺼짐**이 뜨고 자막이 지워집니다.
- 다시 쓰려면 **세션 열기**를 누릅니다.
- PC에서는 포트 전달기 터미널을 `Ctrl+C`로 닫고, `adb -s emulator-5554 forward --remove tcp:47001`을 실행합니다.

### 7. 주행 중 동작 확인 (선택)

- 기어는 Pleos의 Virtual Console에서 바꿉니다. 에뮬레이터 화면 위쪽의 `P R N D`는 표시만 하고, 눌러도 바뀌지 않습니다.
  1. `adb -s emulator-5554 forward tcp:8088 tcp:8088`을 실행합니다.
  2. PC 브라우저에서 `http://127.0.0.1:8088/`을 엽니다.
  3. Emulation Controls의 **Motion**에서 기어를 D로 바꿉니다. 자세한 화면은 [Virtual Console 안내](https://document.pleos.ai/en/docs/pleos-only/app-test-guide/virtual-console-guide)를 봅니다.
- 기어가 D이면 새로 QR을 찍은 폰에는 **주행 중 연결 불가**가 뜹니다.
- 이미 연결된 폰은 그대로 이어집니다.
- 기어가 P가 아니면 세션을 새로 열거나 연결 설정을 바꿀 수 없습니다.

### 이럴 때는

| 화면에 뜬 말 | 할 일 |
|---|---|
| 차: **Wi-Fi 확인** | 에뮬레이터라면 3-3처럼 연결 설정에 PC 주소를 넣습니다. |
| 폰: **연결 실패 · Wi-Fi 확인** | 폰과 PC가 같은 Wi-Fi인지, 포트 전달기 터미널이 켜져 있는지, 방화벽이 `node`를 막지 않았는지, 연결 설정의 주소가 지금 PC 주소와 같은지 확인합니다. |
| 폰: **QR 만료** / **쓸 수 없는 QR** | QR은 한 번 쓰이거나 시간이 지나면 바뀝니다. 차 화면에 지금 떠 있는 QR을 다시 찍습니다. 예전 버전 차 앱의 QR이나, 집·핫스팟 같은 사설 주소(10.x, 172.16~31.x, 192.168.x)가 아닌 QR도 쓸 수 없습니다. 차 앱과 폰 앱을 이 저장소의 같은 버전으로 설치합니다. |
| 폰: **내보내짐** | 차 화면에서 이 폰을 내보낸 것입니다. 차 화면에 떠 있는 새 QR을 찍어 다시 들어옵니다. |
| 폰: **주행 중 연결 불가** | 기어를 P로 바꾼 뒤 다시 찍습니다. |
| 폰: **연결 가득 참 (4대)** | 다른 폰 하나가 나간 뒤 들어옵니다. |
| 폰: **차 마이크 소리 없음** | 2-2의 Enable Host Microphone Access가 켜져 있는지, 2-2의 Mac·Windows 마이크 허용 설정이 켜져 있는지 확인합니다. |
| 폰: **마이크 권한 필요** | 폰 설정의 앱 권한에서 차담의 마이크를 허용합니다. 폰 마이크를 켜는 것이 아니라 음성 인식에 필요한 권한입니다. |
| 폰: **한국어 인식 데이터 없음** / **이 폰은 자막 불가** | 이 폰에서 기기 안 한국어 음성 인식을 쓸 수 없는 상태입니다. 폰의 음성 인식 설정에서 한국어 데이터를 받을 수 있는지 확인합니다(메뉴 위치는 기기마다 다릅니다). 안 되면 다른 폰으로 시험합니다. |
| 폰: **내비 끝나면 읽음** | 내비 안내가 끝나면 차가 이어서 읽습니다. |
| 폰: **실패: 통화 중** | 통화 중에는 차 스피커로 읽지 않습니다. 통화가 끝난 뒤 다시 보냅니다. |

## 주요 동작

- 앱을 열면 정차(기어 P)를 확인한 뒤 세션이 자동으로 열립니다. 주행 중에는 세션을 열지 않고 새 폰도 받지 않습니다. 이미 연결된 폰은 주행 중에도 이어집니다.
- 폰은 4대까지 연결됩니다. 한 사람이 쓴 글은 다른 폰에도 대화명과 함께 뜹니다.
- 차 화면에 연결된 폰의 대화명이 보이고, 폰마다 **내보내기**로 연결을 끊을 수 있습니다. 내보낸 폰은 새 QR로만 다시 들어옵니다.
- 차와 폰 사이 연결은 TLS 1.3으로 암호화하고, 폰은 QR에 담긴 차 키 지문이 맞을 때만 연결합니다. 폰에서 나가면 재접속 키를 바로 버립니다.
- 같은 폰이 글을 너무 빠르게 연달아 보내면(5개 넘게, 그 뒤 1초에 1개 넘게) 넘친 글은 차가 받지 않습니다.
- 내비 안내 중에는 글 읽기를 기다리고 차 마이크 소리도 보내지 않습니다. 통화 중에는 읽지 않습니다.
- 끄면 QR이 사라지고 연결이 끊기며 폰의 자막이 지워집니다.
- 폰 앱을 처음 열면 사용설명서 5장이 나오고, 홈에서 다시 볼 수 있습니다.
- 폰 앱 설정에서 대화명·테마를 바꾸고, 개인정보 안내와 오픈소스 라이선스를 볼 수 있습니다. 차 앱은 **연결 설정** → **오픈소스 라이선스**에서 봅니다. 앱 아이콘은 기기의 라이트·다크 모드를 따릅니다.
- 자막은 틀릴 수 있어 긴급·안전 안내의 유일한 수단으로 쓰지 않습니다.

## 소스로 빌드하기

JDK 17과 Android SDK(compileSdk 36)가 필요합니다. `local.properties`에 `sdk.dir`를 넣거나 `ANDROID_HOME`을 설정합니다.

```bash
cd car-pleos && ./gradlew assembleDebug testDebugUnitTest
cd phone && ./gradlew assembleDebug testDebugUnitTest
```

차 앱은 Pleos Playground 저장소(`nexus-playground.pleos.ai`)에서 Vehicle SDK를 받습니다.
